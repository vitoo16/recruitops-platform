# Domain Glossary

- **Job**: an active recruitment opportunity.
- **Post**: canonical recruitment content.
- **Post Variant**: platform-specific representation of a Post.
- **Destination**: target page/account/organization/OA/group/manual location.
- **Publication**: one attempt/stateful record of distributing one Post Variant to one Destination.
- **Social Account**: authorized platform identity used for official API operations.
- **Manual Assist**: human-in-the-loop distribution when an official API cannot perform the requested action.
- **Candidate**: a person sourced for recruitment.
- **Application**: Candidate × Job recruitment process.
- **Commission Transaction**: immutable/event-like ledger entry representing earned/adjusted/paid commission.
- **Reconciliation Batch**: grouped commission settlement/export.
